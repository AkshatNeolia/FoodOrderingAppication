# FoodOrderingApplication

## Introduction
FoodOrderingApplication is a Java-based food ordering system designed to provide a seamless and efficient way for users to browse, select, and order food from various restaurants. This application enhances the dining experience by integrating secure payment gateways, order tracking, and user-friendly interfaces, bridging the gap between traditional dining and digital convenience.

## Features
- **User-friendly Interface**: Allows users to easily browse and order food from available restaurants.
- **Secure Payment Gateway**: Supports credit/debit card payments for secure transactions.
- **Real-time Order Tracking**: Enables users to track their orders efficiently.
- **Restaurant Management System**: Helps restaurants manage orders and menus effectively.
- **Efficient Order Processing**: Reduces time consumption and minimizes human errors.
- **Scalability & Security**: Built with Java, ensuring a robust and maintainable system.

## Technologies Used
- **Backend:** Java, Python
- **Frontend:** HTML, JavaScript
- **IDE:** Microsoft Visual Studio Code
- **Browser:** Google Chrome (64-bit)
- **Operating System:** Windows 11
- **Hardware Requirements:** Minimum 8GB RAM

## Installation & Setup
### Prerequisites:
1. Install **Java JDK** (version 8 or higher)
2. Install **Python** (if required for backend processing)
3. Install **Visual Studio Code**
4. Install **Google Chrome** (for testing frontend)

### Steps to Run the Application:
1. Clone the repository:
   ```bash
   git clone https://github.com/AkshatNeolia/FoodOrderingApplication.git
   ```
2. Navigate to the project directory:
   ```bash
   cd FoodOrderingApplication
   ```
3. Compile and run the Java backend:
   ```bash
   javac FoodOrderingApplication.java
   java FoodOrderingApplication
   ```
4. Open the HTML frontend in a browser:
   ```
   Open index.html in Google Chrome
   ```
